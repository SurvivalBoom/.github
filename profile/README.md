# 💫 SurvivalBoom Network 💫
**SurvivalBoom** - один з кращих український майнкрафт серверів. Ми створюємо інновації для українського ком'юніті.
Наша мета - створити сильну українську спільноту та поширювати якісний контент, щоб врятувати більше людей які постраждали від вірусу русифікації.
